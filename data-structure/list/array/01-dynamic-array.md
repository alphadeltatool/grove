## 백지 인출 (내 답)

### Q1. `int[]`(배열)는 왜 크기가 고정인가? (메모리 관점에서)
컴퓨터의 메모리는 연속된 공간으로 구성되어있다. 배열은 연속된 메모리 공간에 데이터를 저장 하기 떄문에,
배열을 생성할때, 크기를 미리 정해야한다. 동적으로 할당하면 중간에 메모리 공간이 부족할 수 있고, 연속된 공간을 확보 할 수 없어 서 배열을 늘릴수가 없다.


### Q2. `ArrayList.add(x)`를 호출하면 내부에서 무슨 일이 일어나나?
ArrayList 는 ADD 를 할경우 내부에서 현재 배열의 SIZE 를 확인하는 변수가 있어서 ,  그 변수로 사이즈를 확인한뒤 새로운 인덱스에 넣는다
따라서 O(1) 의 시간복잡도를 가진다.

### Q3. ArrayList가 꽉 차면 크기를 몇 배로 늘리나? 왜 매번 1칸씩 안 늘리나?
ArrayList 는 배열의 크기가 꽉차면 일반적으로 기존 사이즈의 1.5 배를 늘린다
매번 1칸씩 안늘리는 이유는 add 할때마다 배열을 새로만들고 기존 배열의 데이터를 복사하는 작업이 필요하기 때문에, 1칸씩 늘리면 성능이 매우 저하되기 때문이다. 따라서 일정 비율로 늘려서 복사 횟수를 줄이는 것이다.

### Q4. ArrayList는 왜 "중간 삽입/삭제"가 느린가?
중간에 삽입/삭제를 할경우  같은 배열 안에서 뒤 요소들을 한 칸씩 밀거나(삽입) 당기는(삭제) 작업 때문 O(n) 의 시간복잡도를 가진다. 따라서 중간 삽입/삭제는 느리다.

## 오늘 배운 것 3줄
연속메모리라 고정 / size로 O(1) / grow는 가끔이라 평균 O(1)
