# 🌳 my-estudy — 나의 지식의 숲

> 배운 걸 "내 말로" 적어서 쌓는 곳. 강의를 다시 보지 않기 위해, 그리고 안 까먹기 위해.
> 시청은 기억에 안 남는다. **백지에 쓰고, 직접 구현할 때만** 는다.

7년차 백엔드 개발자의 실력·성장 기록. 목적은 순수 실력과 성장감(+이직 대비).
영감: [rlaope/estudy](https://github.com/rlaope/estudy)

## 원칙
- **인풋 < 아웃풋.** 강의 재생 금지. 백지인출 → 구현 → 문제 → 커밋.
- **완강했어도 기억 안 나면 다시 안 본다.** 강의는 "정답지"로만 힐끗.
- **하루 = 개념 1개 → 노트 1개 → 커밋 1개.**
- **잠이 곧 기억 굳히기.** 밀도 있게 하고 잘 잔다.

## 구조
```
essentials/        성장·AI시대·커리어 회고
data-structure/    자료구조 노트 + 구현
database/          DB 노트 + 쿼리
backend/           스프링/JPA 정리 (프로젝트 하며)
jvm-concurrency/   JVM·동시성
network/           네트워크
TIL/               하루 한 줄
```

- 코칭 규칙: [CLAUDE.md](CLAUDE.md)
