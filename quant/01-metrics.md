# 퀀트 1단계 — 평가지표 3종 (CAGR / MDD / 샤프지수)

> 2026-10-10(토) 학습. 코드: `quant/Mdd.java`, `quant/Sharpe.java`

## 왜 3개나 필요한가

"이 전략 수익률 100%예요"라는 말엔 정보가 거의 없음. 세 가지가 빠져있어서.

```
빠진 것                      메꾸는 지표
─────────────────────────────────────────
얼마 동안?                    CAGR
가는 길에 얼마나 꼬라박았나?    MDD
운인가 실력인가?               샤프지수
```

---

## ① CAGR (연평균 복리 수익률)

```
1000만원이 2년 뒤 2000만원.  매년 몇 %씩?

[직관]  100% ÷ 2년 = 연 50%?
[검산]  1000 × 1.5 = 1500
        1500 × 1.5 = 2250    ← 2000이어야 하는데 초과! 틀림

[이유]  2년차엔 원금 1000이 아니라 불어난 1500에 50%가 붙음 = 복리

[정답]  (1+r)² = 2  →  1+r = √2 = 1.414  →  r = 41.4%
[검산]  1000 × 1.414 = 1414
        1414 × 1.414 = 2000  ✓
```

**공식**: `CAGR = (최종 / 최초)^(1 / 년수) - 1`

**`^(1/n)` 이 뭔지** (여기서 막혔던 부분):
```
3^2 = 3×3 = 9          ← 위 숫자 = 몇 번 곱할지
9^(1/2) = 3            ← 두 번 곱해서 9가 되는 수 (제곱근)
8^(1/3) = 2            ← 세 번 곱해서 8이 되는 수
2^(1/2) = 1.414        ← CAGR에서 나온 그 숫자

분모 = 몇 번 곱할 건지.  n년 투자 → n번 곱해야 하니 ^(1/n)
```

**자바**: `Math.pow(2, 1.0 / 2)` — `1/2`로 쓰면 정수나눗셈이라 0이 됨. `1.0` 필수.

## ② MDD (최대 낙폭)

고점 대비 가장 깊이 떨어진 비율. **"최악일 때 얼마나 꼬라박았나"**

```
자산:  1000 → 1200 → 900 → 1500 → 600 → 2000

자산    그때까지 최고점   낙폭
──────────────────────────────────────────
1000    1000            0%
1200    1200            0%
900     1200            (1200-900)/1200 = 25%
1500    1500            0%
600     1500            (1500-600)/1500 = 60%   ← 제일 깊음
2000    2000            0%

MDD = 60%
```

**주의**: 기준은 "전체 최고점"이 아니라 **"그 시점까지의 최고점"**. 600일 때 기준은 1500 (2000은 아직 안 왔음).

### 왜 CAGR보다 중요할 수 있나

```
백테스트 결과: "2년 뒤 2배"
숨은 전제:     "그 2년 동안 한 번도 안 팔고 버텼다면"

MDD 70% 전략에 1억을 넣으면 실제로:
  1월     1억
  11월    5천만
  다음해2월 3천만    ← 7천만원 사라진 화면을 매일 봄
  12월    2억       ← 백테스트가 말하는 결과

대부분 3천만 구간에서 팔아버림 → 7천만 손실 확정, 뒤의 2억은 남 얘기.
```

```
CAGR  =  끝까지 버텼다면 얻었을 돈
MDD   =  버티려면 얼마나 아파야 하는지
```

MDD가 내가 견딜 수준을 넘으면 **그 수익률은 그림의 떡**.

## ③ 샤프지수 (변동성 대비 수익)

같은 수익이면 덜 흔들린 쪽이 좋다. 그 "흔들림"을 숫자로 만든 게 표준편차.

```
전략 A 월수익:   +3%,  +1%,  +2%,  +2%    → 평균 2%  (꾸준)
전략 B 월수익:  +20%, -15%, +18%, -15%    → 평균 2%  (롤러코스터)

평균만 보면 똑같음. 근데 A는 실력, B는 운일 가능성이 큼.
```

### 표준편차 5단계 (전략 A)

```
데이터: 3, 1, 2, 2

① 평균          (3+1+2+2)/4 = 2
② 편차          +1, -1, 0, 0
③ 제곱          1, 1, 0, 0        ← 음수 없애려고. 안 그러면 +1-1=0 돼버림
④ 제곱의 평균    (1+1+0+0)/4 = 0.5  (= 분산)
⑤ 제곱근        √0.5 = 0.71        ← 표준편차
```

### 결과 비교

```
         평균수익   표준편차   샤프 (= 평균 ÷ 표준편차)
────────────────────────────────────────────────
전략 A     2.0      0.707      2.83
전략 B     2.0     17.01       0.12      ← 24배 차이
```

### 읽는 기준

```
1 미만    별로
1 ~ 2     괜찮음
2 ~ 3     좋음
3 이상    의심 (과최적화 가능성 — 다음 단계 주제)
```

**진짜 공식**: `(수익률 - 무위험수익률) / 표준편차`
무위험수익률 = 예금·국채처럼 가만히 둬도 받는 이자. "예금보다 더 번 부분"만 실력으로 치겠다는 뜻. 여기선 0으로 단순화.

## 오늘 막혔던 지점

```
1. ^(1/2) 표기를 모름          → 거듭제곱/제곱근부터 작은 숫자로 다시
2. MDD의 maxDd 갱신 로직        → "돌면서 본 것 중 최댓값만 기억" 으로 정리
3. peak = v 를 v = peak 로 씀   → 대입 방향 반대. MyBST 때와 같은 실수 패턴 (약점)
4. return 0 을 안 고침          → 계산해놓고 안 돌려줌
5. mean()에서 루프 안에서 매번 나눔 → "다 더하고 마지막에 한 번 나눈다"로 정리
```
